# 17. Glossary

| Term | Definition | Chapter |
|---|---|---|
| **Aliasing XOR mutation** | The core invariant: data may have many readers or one writer, never both | 3 |
| **anyhow** | Application-side error crate: type-erased `anyhow::Error` + `.context()` chains | 6 |
| **Arc\<T\>** | Atomically reference-counted shared-ownership pointer; thread-safe Rc | 10, 11 |
| **Associated function** | Function in an `impl` without `self` (e.g. `String::new`); called with `::` | 4 |
| **Associated type** | Type placeholder inside a trait (`Iterator::Item`); one choice per implementor | 7 |
| **Auto trait** | Trait derived structurally by the compiler (`Send`, `Sync`) | 11 |
| **Borrow checker** | Compiler pass enforcing reference rules (counts, lifetimes) | 3 |
| **Box\<T\>** | Owned heap allocation; unique pointer | 10 |
| **Builder pattern** | Chained by-value methods configuring a value, finished by `.build()` | 15 |
| **Cargo** | Build system + package manager + test runner | 1 |
| **Cargo.lock** | Exact resolved dependency versions; reproducible builds | 1, 8 |
| **Cell\<T\> / RefCell\<T\>** | Interior mutability: copy-in/out vs runtime borrow counting (panics on violation) | 10 |
| **Channel (mpsc)** | Message-passing pipe; `send` moves values between threads/tasks | 11, 12 |
| **Clone / Copy** | Explicit duplication trait / implicit bitwise-copy marker trait | 3 |
| **Closure** | Anonymous function capturing environment by ref, mut ref, or move | 9 |
| **Coherence / orphan rule** | An impl requires the trait or type to be crate-local | 7 |
| **Cow\<'a, T\>** | Clone-on-write: borrowed until mutation forces an owned copy | 10 |
| **Crate** | Compilation unit — one library or one binary | 1, 8 |
| **Deref coercion** | Auto-conversion `&String → &str`, `&Box<T> → &T` via the `Deref` trait | 10 |
| **Drop** | Destructor trait; runs deterministically at scope exit (RAII) | 10 |
| **dyn Trait** | Trait object: fat pointer (data + vtable), dynamic dispatch | 7 |
| **Edition** | Opt-in syntax epoch (2015/2018/2021/2024); crates on different editions interoperate | 1 |
| **Elision** | Compiler filling in lifetime annotations by three rules | 7 |
| **entry API** | HashMap upsert: `map.entry(k).or_insert(v)` — one lookup | 5 |
| **Executor / runtime** | Library that polls futures (Tokio); not built into the language | 12 |
| **Fat pointer** | Two-word pointer: slice (ptr+len) or trait object (ptr+vtable) | 3, 7 |
| **Feature flag** | Cargo conditional-compilation switch; must be additive | 8 |
| **FFI** | Foreign function interface — `extern "C"`, `#[repr(C)]`, CString | 14 |
| **Fn / FnMut / FnOnce** | Closure traits: read captures / mutate captures / consume captures | 9 |
| **Future** | Lazy async value; compiled to a state machine, driven by polling | 12 |
| **Generics** | Type parameters compiled by monomorphization — zero runtime cost | 7 |
| **Hygiene** | Macro-internal names can't collide with call-site names | 14 |
| **Interior mutability** | Mutation through `&self` (Cell, RefCell, Mutex, atomics) | 10 |
| **Iterator adapter / consumer** | Lazy transform (`map`, `filter`) / chain-running finisher (`collect`, `sum`) | 9 |
| **Lifetime (`'a`)** | Named borrow duration relating inputs to outputs; compile-time only | 7 |
| **match ergonomics** | Matching through references auto-binds by reference | 4 |
| **Miri** | Interpreter that detects undefined behavior in unsafe code | 13, 14 |
| **Monomorphization** | One specialized compiled copy of generic code per concrete type | 7 |
| **Move semantics** | Assignment transfers ownership and invalidates the source | 3 |
| **Mutex\<T\> / RwLock\<T\>** | Lock *owning* its data — access only via guard; auto-unlock on drop | 11 |
| **Newtype** | Single-field wrapper struct for type safety (`struct UserId(u64)`) | 4, 15 |
| **Niche optimization** | Enum layout trick: `Option<&T>` is pointer-sized | 4 |
| **NLL** | Non-lexical lifetimes — borrows end at last use | 3 |
| **no_std** | Building without the standard library (core/alloc only) | 14 |
| **Object safety** | Conditions for a trait to be usable as `dyn` (no `Self` returns, etc.) | 7 |
| **Option\<T\>** | `Some(T) | None` — Rust's null replacement | 4 |
| **Ownership** | Every value has exactly one owner; dropped at owner's scope exit | 3 |
| **Panic** | Unrecoverable error: unwind (run Drops) or abort | 6 |
| **Pattern matching** | Destructuring + exhaustiveness checking (`match`, `if let`, `let else`) | 4 |
| **Pin** | Guarantee a value won't move in memory; needed for self-referential futures | 12 |
| **Poisoning** | Mutex flagged after a panic while locked; `lock()` returns Err | 11 |
| **Proc macro** | Compile-time function on token streams: derive / attribute / function-like | 14 |
| **RAII** | Resource lifetime tied to value lifetime; cleanup in `Drop` | 3, 10 |
| **Rc\<T\>** | Reference-counted shared ownership; single-threaded | 10 |
| **Result\<T, E\>** | `Ok(T) | Err(E)` — recoverable errors as values | 6 |
| **rustup / rustc** | Toolchain manager / the compiler itself | 1 |
| **Send / Sync** | May move to another thread / may be shared (`&T`) across threads | 11 |
| **Shadowing** | Rebinding a name to a new variable (type may change) | 2 |
| **Slice (`&[T]`, `&str`)** | Borrowed view of contiguous data: (ptr, len) | 3, 5 |
| **Smart pointer** | Pointer type with extra behavior via `Deref` + `Drop` | 10 |
| **Trait / trait bound** | Shared behavior contract / constraint on a generic (`T: Display`) | 7 |
| **Trait object** | See dyn Trait | 7 |
| **Turbofish** | Explicit generic args: `parse::<i32>()`, `collect::<Vec<_>>()` | 2, 9 |
| **Typestate** | Encoding state machines as distinct types so invalid ops don't compile | 15 |
| **Undefined behavior (UB)** | Contract violation in unsafe code; anything may happen | 14 |
| **Unit type `()`** | The empty value; what statements and `;`-terminated expressions yield | 2 |
| **unsafe** | Block/fn unlocking five compiler-unverifiable operations; checker stays on | 14 |
| **Vec\<T\>** | Growable heap array: (ptr, len, capacity) | 5 |
| **Weak\<T\>** | Non-owning Rc/Arc handle; breaks cycles; `upgrade() -> Option` | 10 |
| **Workspace** | Multi-crate repo sharing one lockfile and target dir | 8 |
| **Zero-cost abstraction** | High-level constructs compiling to code as fast as hand-written low-level | 1, 9 |
| **`?` operator** | Early-return propagation of `Err`/`None` with `From` conversion | 6 |
| **`'static`** | Lifetime bound: "contains no non-static borrows" (owned data qualifies) | 7 |
