# 3. Lambda Expression

Lambda expressions were introduced in **Java 8** to bring **functional programming features** into Java. They allow you to write cleaner, more concise code by replacing **anonymous inner classes** with simpler expressions.

---

## 3.1 What is a Lambda Expression?

- A **Lambda Expression** is a short block of code that takes in parameters and returns a value.
- It is similar to methods, but they do not need a name and can be implemented directly in the body of a method.
- They are mostly used to define the **implementation of functional interfaces** (an interface with only one abstract method).

### Syntax

```java
(parameter1, parameter2, ...) -> { expression/body }

```

---

## 3.2 Functional Interface Requirement

- A Lambda Expression can only be used with a **functional interface**.
- Example: `Runnable`, `Callable`, `Comparator`, or any user-defined interface with a **@FunctionalInterface** annotation.

```java
@FunctionalInterface
interface MyFunctionalInterface {
    void sayHello(String name);
}

```

---

## 3.3 Example of Lambda Expression

```java
@FunctionalInterface
interface Greeting {
    void greet(String message);
}

public class LambdaExample {
    public static void main(String[] args) {
        Greeting g1 = (msg) -> System.out.println("Hello, " + msg);
        g1.greet("World");
    }
}

```

**Output:**

```
// Hello, World

```

---

## 3.4 Benefits of Lambda Expressions

1. **Conciseness** – less boilerplate code.
2. **Readability** – makes code cleaner.
3. **Encourages functional programming** in Java.
4. **Easier to use APIs like Streams**.

---

## 3.5 Types of Lambda Expressions

1. **No parameter**

   ```java
   () -> System.out.println("Hello Lambda!");

   ```

2. **Single parameter**

   ```java
   (x) -> x * x;

   ```

3. **Multiple parameters**

   ```java
   (a, b) -> a + b;

   ```

---

## 3.6 Using Lambda with Built-in Functional Interfaces

### Example 1: Runnable

```java
public class LambdaRunnable {
    public static void main(String[] args) {
        Runnable r = () -> System.out.println("Running in a thread!");
        new Thread(r).start();
    }
}

```

**Output:**

```
// Running in a thread!

```

---

### Example 2: Comparator

```java
import java.util.*;

public class LambdaComparator {
    public static void main(String[] args) {
        List<String> names = Arrays.asList("Zara", "Alex", "Bob");

        Collections.sort(names, (a, b) -> a.compareTo(b));
        System.out.println(names);
    }
}

```

**Output:**

```
// [Alex, Bob, Zara]

```

---

### Example 3: Predicate (checks conditions)

```java
import java.util.function.Predicate;

public class LambdaPredicate {
    public static void main(String[] args) {
        Predicate<Integer> isEven = (n) -> n % 2 == 0;

        System.out.println(isEven.test(10)); // true
        System.out.println(isEven.test(7));  // false
    }
}

```

---

## 3.7 Lambda with Streams API

```java
import java.util.*;

public class LambdaStreams {
    public static void main(String[] args) {
        List<Integer> numbers = Arrays.asList(1,2,3,4,5,6);

        numbers.stream()
               .filter(n -> n % 2 == 0)
               .map(n -> n * n)
               .forEach(n -> System.out.println(n));
    }
}

```

**Output:**

```
// 4
// 16
// 36

```

---

## 3.8 Method References (Shorthand for Lambda)

Sometimes Lambda expressions just call an existing method. Instead of writing a lambda, you can use a **method reference**.

```java
import java.util.*;

public class MethodReferenceExample {
    public static void main(String[] args) {
        List<String> names = Arrays.asList("John", "Alice", "Bob");

        names.forEach(System.out::println);
    }
}

```

**Output:**

```
// John
// Alice
// Bob

```

---

## 3.9 Variable Capture in Lambdas

Lambdas can use variables from the enclosing scope:

```java
public class LambdaCapture {
    public static void main(String[] args) {
        String prefix = "Hello ";

        Runnable r = () -> System.out.println(prefix + "World");
        r.run();
    }
}

```

**Output:**

```
// Hello World

```

⚠️ Note: Variables used must be **effectively final** (not modified after initialization).

---

## 3.10 Limitations of Lambda Expressions

1. Can only be used with **functional interfaces**.
2. Not suitable for very complex logic (use regular methods instead).
3. Can make debugging harder (stack traces less clear).

---

✅ **Summary**:

- Lambda expressions simplify code by removing boilerplate.
- They work with **functional interfaces**.
- Widely used in **Streams, Collections, and concurrency**.
- Support **method references** and **variable capture**.
