## 2.1 Classes and Objects

```java
class Car {
    String brand;
    int speed;

    void drive() {
        System.out.println(brand + " drives at " + speed + " km/h");
    }
}

public class Main {
    public static void main(String[] args) {
        Car c = new Car();
        c.brand = "Tesla";
        c.speed = 120;
        c.drive();
    }
}

```

**Output:**

```
Tesla drives at 120 km/h
```

## 2.2 Constructors

```java
class Person {
    String name;
    int age;

    Person() { // default constructor
        name = "Unknown";
        age = 0;
    }

    Person(String n, int a) { // parameterized
        name = n;
        age = a;
    }

    Person(Person p) { // copy constructor
        name = p.name;
        age = p.age;
    }

    void show() { System.out.println(name + " is " + age); }
}

public class Main {
    public static void main(String[] args) {
        Person p1 = new Person("Alice", 22);
        Person p2 = new Person(p1);
        p1.show(); // Alice is 22
        p2.show(); // Alice is 22
    }
}

```

## 2.6 Abstraction

| **Points** | **Abstract Class** | **Interface** |
| --- | --- | --- |
| **Definition** | Cannot be instantiated; contains both abstract (without implementation) and concrete methods (with implementation) | Specifies a set of methods a class must implement; methods are abstract by default. |
| **Implementation Method** | Can have both implemented and abstract methods. | Methods are abstract by default; Java 8, can have default and static methods. |
| **Inheritance** | class can inherit from only one abstract class. | A class can implement multiple interfaces. |
| **Access Modifiers** | Methods and properties can have any access modifier (public, protected, private). | Methods and properties are implicitly public. |
| **Variables** | Can have member variables (final, non-final, static, non-static). | Variables are implicitly public, static, and final (constants). |

```java
abstract class Vehicle {
    abstract void start();
}

class Bike extends Vehicle {
    void start(){ System.out.println("Bike starts with a kick"); }
}

public class Main {
    public static void main(String[] args) {
        Vehicle v = new Bike();
        v.start();
    }
}

```

**Output:**

```
Bike starts with a kick

```

### Example of Abtracts

```java
// Abstract base class
abstract class Animal {
    // Instance variable
    String name;

    // Static variable
    static int count = 0;

    // Final variable (constant)
    final String kingdom = "Animalia";

    // Constructor
    Animal(String name) {
        this.name = name;
        count++;
        System.out.println("Animal constructor called for: " + name);
    }

    // Abstract method (must be implemented by subclass)
    abstract void makeSound();

    // Concrete method
    void eat() {
        System.out.println(name + " is eating.");
    }

    // Final method (cannot be overridden in subclass)
    final void breathe() {
        System.out.println(name + " is breathing.");
    }

    // Static method
    static void showCount() {
        System.out.println("Total animals created: " + count);
    }
}

// Subclass implementing abstract method
class Dog extends Animal {
    Dog(String name) {
        super(name);
    }

    @Override
    void makeSound() {
        System.out.println(name + " says: Woof Woof!");
    }
}

// Another subclass
class Cat extends Animal {
    Cat(String name) {
        super(name);
    }

    @Override
    void makeSound() {
        System.out.println(name + " says: Meow Meow!");
    }
}

// Main class to test
public class AbstractClassDemo {
    public static void main(String[] args) {
        Animal dog = new Dog("Buddy");
        dog.makeSound();   // Abstract method implemented in Dog
        dog.eat();         // Concrete method from Animal
        dog.breathe();     // Final method from Animal
        System.out.println("Kingdom: " + dog.kingdom);

        Animal cat = new Cat("Kitty");
        cat.makeSound();   // Abstract method implemented in Cat
        cat.eat();
        cat.breathe();
        System.out.println("Kingdom: " + cat.kingdom);

        // Static method
        Animal.showCount();
    }
}

```

## 2.7 `this` and `super`

```java
class Parent {
    int num = 10;
}

class Child extends Parent {
    int num = 20;

    void show() {
        System.out.println("this.num = " + this.num);
        System.out.println("super.num = " + super.num);
    }
}

public class Main {
    public static void main(String[] args) {
        new Child().show();
    }
}

```

**Output:**

```
this.num = 20
super.num = 10

```

## 2.9 Final Keyword

1. **Final variable** → Value can’t be changed once assigned.
    
    ```java
    final int MAX_USERS = 100;
    ```
    
2. **Final method** → Method can’t be overridden in subclasses.
    
    ```java
    public final void display() { System.out.println("Hello"); }
    ```
    
3. **Final class** → Class can’t be extended (no inheritance).
    
    ```java
    final class Constants {}
    ```

## 2.12 Enumeration (Enum)

```java
enum Day {
    MONDAY("Start"), FRIDAY("End"), SUNDAY("Holiday");

    private String msg;
    Day(String msg){ this.msg = msg; }
    public String getMsg(){ return msg; }
}

public class Main {
    public static void main(String[] args) {
        for(Day d: Day.values())
            System.out.println(d + " -> " + d.getMsg());
    }
}

```

**Output:**

```
MONDAY -> Start
FRIDAY -> End
SUNDAY -> Holiday

```

# 📊 Comparison Tables

### 🔹 Types of Constructors

| Type | Example | Use Case |
| --- | --- | --- |
| Default | `Person(){}` | Initialize with default values |
| Parameterized | `Person(String n, int a){}` | Initialize with given values |
| Copy | `Person(Person p){}` | Clone an object |

---

### 🔹 Abstract Class vs Interface

| Feature | Abstract Class | Interface (Java 8+) |
| --- | --- | --- |
| Methods | Can have abstract + concrete | Only abstract (default + static allowed) |
| Variables | Can be instance vars | Only `public static final` (constants) |
| Inheritance | Single inheritance only | Multiple inheritance supported |
| Use Case | Base class with partial impl. | Contract (what must be done) |

---

### 🔹 Static vs Instance Members

| Feature | Static | Instance |
| --- | --- | --- |
| Belongs to | Class | Object |
| Memory | One copy shared | Each object has own copy |
| Access | `ClassName.member` | `object.member` |
| Example | `Math.sqrt()` | `obj.toString()` |
