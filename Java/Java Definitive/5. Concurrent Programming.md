# Concurrent Tasks

## Runnable

Runnable interface describes a task you want to run, perhaps concurrently with others, without returning any value.

```java
public interface Runnable {
	void run();
}

```

## Executor

- **Executor** service schedules and executes tasks, choosing the threads on which to run them
- The **Executors** class has factory methods for executor services with different scheduling policies

```java
Runnable task = () -> { ... };
ExecutorService executor = ...;
executor.execute(task);
```

### Cached Thread Pool

- Used for bulk tasks which are short lived or spend most of their time waiting.
- Idle thread is used if possible, else new thread get created if all are busy.
-

```java
exec = Executors.newCachedThreadPool();
```

### Fixed Thread Pool

- A pool with a fixed number of threads.
- When you submit a task, it is queued up until a thread becomes available.
- For compute intensive task and resource consumption of service.

```java
int processors = Runtime.getRuntime().availableProcessors();
```

## Future <V>

- An object that represents a computation whose result will be available at some future time.
- get method of future blocks until the result is available or until the timeout has been reached.

```java
V get() throws InterruptedException,
ExecutionException
V get(long timeout, TimeUnit unit)
throws InterruptedException, ExecutionException,
TimeoutException;
boolean cancel(boolean mayInterruptIfRunning)
boolean isCancelled()
boolean isDone()
```

## Callable <V>

- A task that computes a result, and returns it in form of Future.

```java
public interface Callable<V> {
		V call() throws Exception;
}
```

```java
ExecutorService executor =
Executors.newFixedThreadPool();
Callable<V> task = ...;
Future<V> f = executor.submit(task);
```

### Invoke All

To execute on multiple Callable task invoke all can be used. This call blocks until all tasks have completed. then return result.

```java
String word = ...;
Set<Path> paths = ...;
var tasks = new ArrayList<Callable<Long>>();
for (Path p : paths) tasks.add(
() -> { return number of occurrences of word in p });
List<Future<Long>> futures = executor
		.invokeAll(tasks); // This call blocks until all tasks have completed
long total = 0;
for (Future<Long> f : futures) total += f.get();
```

### Invoke Any

Returns as soon as any one of the submitted tasks has completed normally

```java
String word = ...;
Set<Path> files = ...;
var tasks = new ArrayList<Callable<Path>>();
for (Path p : files) tasks.add(
() -> { if (word occurs in p) return p; else throw
... });
Path found = executor.invokeAny(tasks);
```

# Asynchronous Computations

## Supplier

A function which does not take in any argument but produces a value of type T

```java
Supplier<Double> randomValue = () -> Math.random();
System.out.println(randomValue.get());
```

## Completable Futures

- The **CompletableFuture** class implements the **Future** interface, and it provides a second mechanism for obtaining the result.
- You register a callback that will be invoked (in some thread) with the result once it is available

| Method          | Lambda Type              | Signature        | Purpose                  |
| --------------- | ------------------------ | ---------------- | ------------------------ |
| `runAsync`      | `Runnable`               | `() -> void`     | Run task, no result      |
| `supplyAsync`   | `Supplier<T>`            | `() -> T`        | Run task, produce result |
| `thenApply`     | `Function<T, R>`         | `(T) -> R`       | Transform result         |
| `thenAccept`    | `Consumer<T>`            | `(T) -> void`    | Consume result           |
| `thenCombine`   | `BiFunction<T, U, R>`    | `(T, U) -> R`    | Merge two futures        |
| `allOf`         | —                        | —                | Wait for all futures     |
| `anyOf`         | —                        | —                | Get first finished       |
| `exceptionally` | `Function<Throwable, T>` | `(Throwable)->T` | Error recovery           |

```java
import java.util.concurrent.*;

public class CompletableFutureDemo {

    public static void main(String[] args) throws Exception {
        // 1. Run async task (no return)
        CompletableFuture<Void> task1 = CompletableFuture.runAsync(() -> {
            System.out.println("Task 1 running on: " + Thread.currentThread().getName());
        });

        // 2. Supply async (returns a result)
        CompletableFuture<String> task2 = CompletableFuture.supplyAsync(() -> {
            sleep(1000);
            return "Hello";
        });

        // 3. Transform result (thenApply)
        CompletableFuture<String> task3 = task2.thenApply(str -> str + " World");

        // 4. Consume result (thenAccept)
        task3.thenAccept(result -> {
            System.out.println("Task 3 result: " + result);
        });

        // 5. Combine two futures
        CompletableFuture<Integer> num1 = CompletableFuture.supplyAsync(() -> 10);
        CompletableFuture<Integer> num2 = CompletableFuture.supplyAsync(() -> 20);

        CompletableFuture<Integer> combined = num1.thenCombine(num2, (a, b) -> a + b);
        combined.thenAccept(sum -> System.out.println("Combined sum: " + sum));

        // 6. Run tasks in parallel (allOf)
        CompletableFuture<String> f1 = CompletableFuture.supplyAsync(() -> {
            sleep(500);
            return "A";
        });
        CompletableFuture<String> f2 = CompletableFuture.supplyAsync(() -> {
            sleep(1000);
            return "B";
        });
        CompletableFuture<String> f3 = CompletableFuture.supplyAsync(() -> {
            sleep(1500);
            return "C";
        });

        CompletableFuture<Void> all = CompletableFuture.allOf(f1, f2, f3);
        all.thenRun(() -> {
            try {
                System.out.println("All results: " +
                        f1.get() + ", " + f2.get() + ", " + f3.get());
            } catch (Exception e) {
                e.printStackTrace();
            }
        });

        // 7. AnyOf (first completed)
        CompletableFuture<Object> any = CompletableFuture.anyOf(f1, f2, f3);
        any.thenAccept(first -> System.out.println("First completed: " + first));

        // 8. Error handling
        CompletableFuture<String> errorTask = CompletableFuture.supplyAsync(() -> {
            if (true) throw new RuntimeException("Boom!");
            return "Success";
        });

        errorTask
            .exceptionally(ex -> "Recovered from error: " + ex.getMessage())
            .thenAccept(System.out::println);

        // Wait for everything to finish
        Thread.sleep(3000);
    }

    private static void sleep(long ms) {
        try { Thread.sleep(ms); } catch (InterruptedException e) { e.printStackTrace(); }
    }
}

```

## Synchronized

- A **modifier** in Java that controls **thread access** to blocks or methods
- Ensures **mutual exclusion** → only one thread at a time executes a synchronized block/method.
- Uses the **object’s intrinsic lock (monitor)**.
- Types:
  1. **Instance method** → lock on `this`.
  2. **Static method** → lock on `ClassName.class`.
  3. **Block** → lock on any chosen object.
- Provides **atomicity + visibility**, but too much synchronization = performance hit.

```java
class Counter {
    private int count = 0;
    private static int staticCount = 0;
    private final Object lock = new Object();
    // 1. Instance method (lock on this)
    public synchronized void increment() {
        count++;
    }
    // 2. Static method (lock on Class object)
    public static synchronized void staticIncrement() {
        staticCount++;
    }
    // 3. Block (lock on custom object)
    public void blockIncrement() {
        synchronized (lock) {
            count++;
        }
    }
    public int getCount() { return count; }
    public static int getStaticCount() { return staticCount; }
}

public class SyncDemo {
    public static void main(String[] args) throws InterruptedException {
        Counter counter = new Counter();
        // Two threads updating shared counter
        Thread t1 = new Thread(() -> {
            for (int i = 0; i < 1000; i++) {
                counter.increment();       // instance method
                Counter.staticIncrement(); // static method
                counter.blockIncrement();  // block
            }
        });
        Thread t2 = new Thread(() -> {
            for (int i = 0; i < 1000; i++) {
                counter.increment();
                Counter.staticIncrement();
                counter.blockIncrement();
            }
        });
        t1.start(); t2.start();
        t1.join(); t2.join();
        System.out.println("Final count: " + counter.getCount());       // 4000
        System.out.println("Final static count: " + Counter.getStaticCount()); // 2000
    }
}

```

# Threads

- **Thread** = lightweight unit of execution.
- Java provides **multithreading** to run tasks concurrently.
- Ways to create a thread:
  1. **Extend `Thread` class** → override `run()`.
  2. **Implement `Runnable`** → pass to `Thread`.
  3. **Implement `Callable` + FutureTask** → returns value.
- Control methods:
  - `start()` → begins execution (calls `run()` internally).
  - `sleep(ms)` → pause thread.
  - `join()` → wait for thread to finish.
  - `setPriority()` → hint to scheduler (not guaranteed).
  - `isAlive()` → check if running.

```java
import java.util.concurrent.*;

// 1. Extending Thread
class MyThread extends Thread {
    public void run() {
        System.out.println("Thread by extending Thread: " + Thread.currentThread().getName());
    }
}

// 2. Implementing Runnable
class MyRunnable implements Runnable {
    public void run() {
        System.out.println("Thread by implementing Runnable: " + Thread.currentThread().getName());
    }
}

public class ThreadDemo {
    public static void main(String[] args) throws Exception {
        // --- 1. Using Thread class ---
        Thread t1 = new MyThread();

        // --- 2. Using Runnable interface ---
        Thread t2 = new Thread(new MyRunnable());

        // --- 3. Using Callable with FutureTask (returns result) ---
        Callable<String> task = () -> {
            Thread.sleep(500);
            return "Result from Callable: " + Thread.currentThread().getName();
        };
        FutureTask<String> futureTask = new FutureTask<>(task);
        Thread t3 = new Thread(futureTask);

        // Start all threads
        t1.start();
        t2.start();
        t3.start();

        // --- 4. Main thread waits for others using join() ---
        t1.join();
        t2.join();
        t3.join();

        // --- 5. Get result from Callable ---
        System.out.println(futureTask.get());

        // --- 6. Anonymous thread with lambda ---
        Thread t4 = new Thread(() -> {
            System.out.println("Thread with lambda Runnable: " + Thread.currentThread().getName());
        });
        t4.start();
        t4.join();

        // --- 7. Main thread info ---
        System.out.println("Main thread: " + Thread.currentThread().getName());
    }
}

```
